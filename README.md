# Nourish — יומן תזונה

ממשק בעברית למעקב אחר ארוחות וערכים תזונתיים, על בסיס מאגר המזון הקיים בפרויקט.

## הפעלה

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

הערכים מחושבים לפי הכמויות ל־100 גרם שב־`food_database.json`. אפשר להרחיב את המאגר על ידי הוספת מזונות לאותו קובץ.
