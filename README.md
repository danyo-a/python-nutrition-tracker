# Nourish — יומן תזונה

יומן תזונה בעברית, עם מאגר מזון אישי, מעקב יומי וייצוא נתונים.

## הפעלה

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## מה אפשר לעשות

- להוסיף מזון למאגר עם קלוריות, חלבון, פחמימות ושומן ל־100 גרם.
- לתעד כמויות לפי ארוחת בוקר, צהריים, ערב או נשנוש.
- לערוך כמויות, להסיר פריטים ולצפות בסיכום היומי.
- לבחור תאריך אחר, לשנות את היעד הקלורי ולהוריד את היומן כ־CSV.

מאכלים חדשים נשמרים ב־`food_database.json` והיומנים נשמרים מקומית ב־`nutrition_log.json` במחשב שבו האפליקציה פועלת. הערכים התזונתיים הם לפי מאגר המזון שהוזן, ל־100 גרם.
